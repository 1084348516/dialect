# Familect 家乡话 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 做一个三语（简/繁/EN）的方言常用语词典静态站：首页 → 方言页 → 词条页，带本地搜索、分类/地区筛选、反馈接口（Cloudflare Pages Functions + D1），部署到 Cloudflare Pages。

**Architecture:** Astro 静态输出。内容放在 `src/content/dialects/*.yaml`，用 zod schema 校验。所有页面由一个 `src/pages/[...path].astro` 路由按「语言 × 页面类型」生成，具体渲染交给 `src/views/` 里的三个视图组件。纯逻辑（路径、繁体转换、搜索、筛选、词条关系、反馈校验）都放在不依赖 Astro 的模块里，用 vitest 测试。反馈接口是一个 Pages Function，业务逻辑在 `src/server/feedback.js`，可以单独测试。

**Tech Stack:** Astro 5、TypeScript、zod 3、opencc-js、@astrojs/sitemap、subset-font、vitest、wrangler（Cloudflare Pages + D1）

**Spec:** `docs/superpowers/specs/2026-10-14-familect-design.md`

**与 spec 的偏差（已有意调整）：**
1. spec 中写的三个 `[...lang]/…` 页面文件，改成一个 `src/pages/[...path].astro` 加三个视图组件。原因是 Astro 对中间位置的 rest 参数支持不够可靠；改动后网址不变。
2. D1 绑定写在 `wrangler.toml` 中，而不是在 Cloudflare 后台绑定。原因是仓库里有 `wrangler.toml` 时，它就是 Pages 配置的唯一来源。
3. 邮件通知额外需要环境变量 `FEEDBACK_EMAIL_FROM`（发件地址，必须是 Email Routing 所在域名下的地址）。
4. 状态为 live 的方言还必须填写 `intro`、`introEn`、`romanization`，否则词条页和方言页会缺内容。

## Global Constraints

- Node ≥ 20；Astro 5，使用 Content Layer API（`src/content.config.ts` + `glob` loader）；静态输出，`trailingSlash: 'always'`，`build.format: 'directory'`
- 不用前端框架；客户端逻辑写在 Astro 组件的 `<script>` 中（TypeScript，由 Astro 打包）
- 语言代码：`zh-hans`（无前缀）、`zh-hant`（`/zh-hant`）、`en`（`/en`）；`<html lang>` 分别为 `zh-Hans`、`zh-Hant`、`en`
- slug 正则：`^[a-z0-9]+(?:-[a-z0-9]+)*$`
- 繁体转换：OpenCC `cn → tw`。**不转换** `text`、`alt`、`homophone`、例句原文，以及所有拼音和英文字段
- 颜色 token：`--bg #F2F0EB`、`--surface #FFFFFF`、`--border #E2DFD8`、`--ink #1C1B19`、`--muted #6B6862`、`--accent #0F5C4D`、`--accent-soft #E3EEEB`、`--warn #A8321E`、`--soon #8A6A1F`
- 反馈类型枚举：`pron`、`translation`、`chars`、`other`；message 1–1000 字，background ≤ 50 字，contact ≤ 100 字；不记录 IP
- 示例数据提示文案：`示例数据，正式上线前需母语者校对。`
- 语言偏好的 localStorage key：`familect-lang`
- 不做深色模式；不使用 Google Fonts 等第三方字体 CDN
- **不做 git 提交**（用户要求）。每个任务的最后一步是「运行全部测试」，不是 commit

## Review Focus

1. **只填了必填字段的词条**（没有例句、各地说法、提示等）：词条页不应出现空的小标题。用示例数据中的「多谢 to-sia」验证，见 Task 11 Step 5 和 Task 13 的 `verify`
2. **格式不对的反馈请求**（不是 JSON、是数组、请求体超大、全是空格）：应返回 400，不应返回 500，也不能写入 D1。见 Task 8 的测试
3. **搜索词只有标点、空格或声调数字**（如 `"  "`、`"6"`、`"？"`）：应返回空结果，不能把所有词条都列出来。见 Task 5 的测试
4. **网址里带未知的筛选参数**（`?cat=nope&region=xx`）：应当作没有筛选，显示全部词条，不报错。见 Task 4 的测试
5. **`status: soon` 的方言**：不生成页面，不进入搜索索引和 sitemap，首页卡片不能点击。见 Task 5 的测试和 Task 13 的 `verify`

- [ ] **Step 3: 实现 `src/i18n/langs.ts`**

```ts
export const LANGS = ['zh-hans', 'zh-hant', 'en'] as const;
export type Lang = (typeof LANGS)[number];
export const DEFAULT_LANG: Lang = 'zh-hans';

export const HTML_LANG: Record<Lang, string> = { 'zh-hans': 'zh-Hans', 'zh-hant': 'zh-Hant', en: 'en' };
export const LANG_LABEL: Record<Lang, string> = { 'zh-hans': '简', 'zh-hant': '繁', en: 'EN' };
export const LANG_STORAGE_KEY = 'familect-lang';

export function prefix(lang: Lang): string {
  return lang === DEFAULT_LANG ? '' : `/${lang}`;
}

export function homePath(lang: Lang): string {
  return `${prefix(lang)}/`;
}

export function dialectPath(lang: Lang, dialectId: string): string {
  return `${prefix(lang)}/${dialectId}/`;
}

export function entryPath(lang: Lang, dialectId: string, entryId: string): string {
  return `${prefix(lang)}/${dialectId}/${entryId}/`;
}

export function pick<T>(lang: Lang, zh: T, en: T): T {
  return lang === 'en' ? en : zh;
}
```

- [ ] **Step 4: 实现 `src/lib/schema.ts`**

```ts
import { z } from 'zod';

export const SLUG_RE = /^[a-z0-9]+(?:-[a-z0-9]+)*$/;
export const RESERVED_IDS = ['zh-hans', 'zh-hant', 'en', 'search', 'fonts', 'api', '_astro'];

const slug = z.string().regex(SLUG_RE, 'must be a slug: lowercase letters, digits and single hyphens');
const text = z.string().trim().min(1);
const optText = z.string().trim().min(1).nullish().transform((v) => v ?? undefined);

const exampleSchema = z.object({ text, pron: text, zh: text, en: text });
const variantSchema = z.object({ region: text, text: optText, note: optText });
const regionSchema = z.object({ id: slug, name: text, nameEn: text });
const categorySchema = regionSchema.extend({ caution: z.boolean().default(false) });

export const entrySchema = z.object({
  id: slug,
  text,
  alt: z.array(text).default([]),
  pron: text,
  homophone: text,
  enReading: text,
  zh: text,
  en: text,
  meaning: optText,
  meaningEn: optText,
  literal: optText,
  note: optText,
  noteEn: optText,
  category: slug,
  regions: z.array(slug).default([]),
  featured: z.boolean().default(false),
  examples: z.array(exampleSchema).default([]),
  variants: z.array(variantSchema).default([]),
});

export const dialectSchema = z
  .object({
    name: text,
    nameEn: text,
    status: z.enum(['live', 'soon']),
    order: z.number().int(),
    reviewed: z.boolean().default(false),
    areas: text,
    areasEn: text,
    intro: optText,
    introEn: optText,
    romanization: z.object({ name: text, nameEn: text }).optional(),
    regions: z.array(regionSchema).default([]),
    categories: z.array(categorySchema).default([]),
    entries: z.array(entrySchema).default([]),
  })
  .superRefine((d, ctx) => {
    const issue = (path: (string | number)[], message: string) => ctx.addIssue({ code: z.ZodIssueCode.custom, path, message });

    if (d.status === 'live') {
      if (d.entries.length === 0) issue(['entries'], 'a live dialect needs at least one entry');
      if (d.categories.length === 0) issue(['categories'], 'a live dialect needs at least one category');
      if (!d.intro) issue(['intro'], 'a live dialect needs intro');
      if (!d.introEn) issue(['introEn'], 'a live dialect needs introEn');
      if (!d.romanization) issue(['romanization'], 'a live dialect needs romanization');
    }

    const dupes = (ids: string[], what: string, key: string) => {
      const seen = new Set<string>();
      ids.forEach((id, i) => {
        if (seen.has(id)) issue([key, i, 'id'], `duplicate ${what} id "${id}"`);
        seen.add(id);
      });
    };
    dupes(d.categories.map((c) => c.id), 'category', 'categories');
    dupes(d.regions.map((r) => r.id), 'region', 'regions');
    dupes(d.entries.map((e) => e.id), 'entry', 'entries');

    const catIds = new Set(d.categories.map((c) => c.id));
    const regionIds = new Set(d.regions.map((r) => r.id));
    d.entries.forEach((e, i) => {
```

```ts
import * as OpenCC from 'opencc-js';
import type { Dialect } from '../lib/schema';
import type { Lang } from './langs';

const cn2tw = OpenCC.Converter({ from: 'cn', to: 'tw' });

export function toHant(s: string): string {
  return cn2tw(s);
}

const opt = (s: string | undefined) => (s === undefined ? undefined : toHant(s));

/** 繁体版只转换中文说明类字段；方言原文、谐音、拼音、英文保持原样。 */
export function localizeDialect(d: Dialect, lang: Lang): Dialect {
  if (lang !== 'zh-hant') return d;
  return {
    ...d,
    name: toHant(d.name),
    areas: toHant(d.areas),
    intro: opt(d.intro),
    romanization: d.romanization && { ...d.romanization, name: toHant(d.romanization.name) },
    regions: d.regions.map((r) => ({ ...r, name: toHant(r.name) })),
    categories: d.categories.map((c) => ({ ...c, name: toHant(c.name) })),
    entries: d.entries.map((e) => ({
      ...e,
      zh: toHant(e.zh),
      meaning: opt(e.meaning),
      literal: opt(e.literal),
      note: opt(e.note),
      examples: e.examples.map((x) => ({ ...x, zh: toHant(x.zh) })),
      variants: e.variants.map((v) => ({ ...v, region: toHant(v.region), note: opt(v.note) })),
    })),
  };
}
```

```ts
import type { Category, Dialect, Entry } from './schema';

export function relatedEntries(d: Dialect, entry: Entry, max = 6): Entry[] {
  return d.entries.filter((e) => e.category === entry.category && e.id !== entry.id).slice(0, max);
}

export function neighbors(d: Dialect, entryId: string): { prev?: Entry; next?: Entry } {
  const i = d.entries.findIndex((e) => e.id === entryId);
  if (i < 0) return { prev: undefined, next: undefined };
  return { prev: d.entries[i - 1], next: d.entries[i + 1] };
}

export function featuredEntries(dialects: Dialect[], max = 4): { dialect: Dialect; entry: Entry }[] {
  return dialects
    .filter((d) => d.status === 'live')
    .flatMap((d) => d.entries.filter((e) => e.featured).map((entry) => ({ dialect: d, entry })))
    .slice(0, max);
}

/** 首页「按场景查」：按分类 id 去重，跳过慎用分类和没有词条的分类。 */
export function sceneLinks(dialects: Dialect[]): { category: Category; dialectId: string }[] {
  const seen = new Set<string>();
  const out: { category: Category; dialectId: string }[] = [];
  for (const d of dialects) {
    if (d.status !== 'live') continue;
    for (const c of d.categories) {
      if (c.caution || seen.has(c.id) || !d.entries.some((e) => e.category === c.id)) continue;
      seen.add(c.id);
      out.push({ category: c, dialectId: d.id });
    }
  }
  return out;
}

export function isCaution(d: Dialect, entry: Entry): boolean {
  return d.categories.some((c) => c.id === entry.category && c.caution);
}
```

```ts
export interface Filter {
  cat?: string;
  region?: string;
}

export function parseFilter(search: string, catIds: string[], regionIds: string[]): Filter {
  const p = new URLSearchParams(search);
  const cat = p.get('cat') ?? '';
  const region = p.get('region') ?? '';
  return {
    cat: catIds.includes(cat) ? cat : undefined,
    region: regionIds.includes(region) ? region : undefined,
  };
}

/** 没有标注地区的词条视为通用，任何地区筛选下都显示。 */
export function matchesFilter(item: { cat: string; regions: string[] }, f: Filter): boolean {
  if (f.cat && item.cat !== f.cat) return false;
  if (f.region && item.regions.length > 0 && !item.regions.includes(f.region)) return false;
  return true;
}

export function filterQuery(f: Filter): string {
  const p = new URLSearchParams();
  if (f.cat) p.set('cat', f.cat);
  if (f.region) p.set('region', f.region);
  const s = p.toString();
  return s ? `?${s}` : '';
}
```

```ts
export interface SearchRecord {
  dialect: string;
  dialectName: string;
  id: string;
  url: string;
  text: string;
  pron: string;
  zh: string;
  en: string;
  keys: string[];
}

/** 去掉声调符号（组合附加符号）、声调数字、空格、连字符、标点和符号，再转成小写。 */
export function normalize(s: string): string {
  return s
    .normalize('NFD')
    .replace(/\p{M}/gu, '')
    .toLowerCase()
    .replace(/[\s\p{P}\p{S}0-9]/gu, '');
}

const splitGloss = (s: string) => [s, ...s.split(/[；;，,、/]/)];

export function buildKeys(e: { text: string; alt: string[]; pron: string; homophone: string; zh: string; en: string }): string[] {
  const raw = [e.text, ...e.alt, e.pron, e.homophone, ...splitGloss(e.zh), ...splitGloss(e.en)];
  return [...new Set(raw.map(normalize).filter(Boolean))];
}

function score(keys: string[], q: string): number {
  let best = 0;
  for (const k of keys) {
    if (k === q) return 3;
    if (k.startsWith(q)) best = Math.max(best, 2);
    else if (k.includes(q)) best = Math.max(best, 1);
  }
  return best;
}

export function searchIndex(index: SearchRecord[], query: string, opts: { dialect?: string; limit?: number } = {}): SearchRecord[] {
  const q = normalize(query);
  if (!q) return [];
  const { dialect, limit = 10 } = opts;
  return index
    .map((r, i) => ({ r, i, s: !dialect || r.dialect === dialect ? score(r.keys, q) : 0 }))
    .filter((x) => x.s > 0)
    .sort((a, b) => b.s - a.s || a.i - b.i)
    .slice(0, limit)
    .map((x) => x.r);
}
```

```ts
import type { Dialect } from './schema';
import { buildKeys, type SearchRecord } from './search';

export function buildSearchRecords(dialects: Dialect[], lang: Lang): SearchRecord[] {
  return dialects
    .filter((d) => d.status === 'live')
    .flatMap((d) =>
      d.entries.map((e) => ({
        dialect: d.id,
        dialectName: pick(lang, d.name, d.nameEn),
        id: e.id,
        url: entryPath(lang, d.id, e.id),
        text: e.text,
        pron: e.pron,
        zh: e.zh,
        en: e.en,
        keys: buildKeys(e),
      })),
    );
}
```

```ts
import { getCollection } from 'astro:content';
import { localizeDialect } from '../i18n/convert';
import type { Lang } from '../i18n/langs';
import { assertDialectId, type Dialect } from './schema';

let cache: Promise<Dialect[]> | undefined;

export function loadDialects(): Promise<Dialect[]> {
  cache ??= getCollection('dialects').then((items) =>
    items
      .map((item) => {
        assertDialectId(item.id);
        return { ...item.data, id: item.id } as Dialect;
      })
      .sort((a, b) => a.order - b.order),
  );
  return cache;
}

export async function getDialects(lang: Lang): Promise<Dialect[]> {
  return (await loadDialects()).map((d) => localizeDialect(d, lang));
}
```

```js
// 按网站实际用字裁剪思源宋体 Bold，输出 woff2 到 public/fonts/，并把文件路径写入 src/generated/font.json。
import { readFile, writeFile, readdir, mkdir, rm } from 'node:fs/promises';
import { createHash } from 'node:crypto';
import { fileURLToPath } from 'node:url';
import path from 'node:path';

const EXTRA = '，。、；：？！“”‘’（）《》「」『』—…·／';

export function collectChars(texts) {
  const set = new Set();
  for (let c = 0x20; c <= 0x7e; c++) set.add(String.fromCharCode(c));
  for (const ch of EXTRA) set.add(ch);
  for (const t of texts) for (const ch of t.normalize('NFC')) if (!/\s/.test(ch)) set.add(ch);
  return [...set].sort().join('');
}

async function main() {
  const root = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..');
  const { default: subsetFont } = await import('subset-font');
  const OpenCC = await import('opencc-js');
  const toHant = OpenCC.Converter({ from: 'cn', to: 'tw' });

  const contentDir = path.join(root, 'src/content/dialects');
  const files = (await readdir(contentDir)).filter((f) => f.endsWith('.yaml')).map((f) => path.join(contentDir, f));
  files.push(path.join(root, 'src/i18n/ui.ts'));
  const texts = await Promise.all(files.map((f) => readFile(f, 'utf8')));
  const chars = collectChars([...texts, ...texts.map(toHant)]);

  const source = await readFile(path.join(root, 'fonts/src/NotoSerifSC-Bold.otf'));
  const woff2 = await subsetFont(source, chars, { targetFormat: 'woff2' });
  const hash = createHash('sha256').update(woff2).digest('hex').slice(0, 10);
  const name = `familect-serif.${hash}.woff2`;

  const outDir = path.join(root, 'public/fonts');
  await rm(outDir, { recursive: true, force: true });
  await mkdir(outDir, { recursive: true });
  await writeFile(path.join(outDir, name), woff2);

  await mkdir(path.join(root, 'src/generated'), { recursive: true });
  await writeFile(path.join(root, 'src/generated/font.json'), `${JSON.stringify({ file: `/fonts/${name}` }, null, 2)}\n`);
  console.log(`font: ${[...chars].length} chars -> public/fonts/${name} (${(woff2.length / 1024).toFixed(1)} KB)`);
}

if (process.argv[1] && path.resolve(process.argv[1]) === fileURLToPath(import.meta.url)) {
  await main();
}
```

```js
// 反馈接口的业务逻辑。和 Cloudflare 运行时无关，邮件发送由调用方注入（见 functions/api/feedback.js）。
export const FEEDBACK_TYPES = ['pron', 'translation', 'chars', 'other'];
const LANGS = ['zh-hans', 'zh-hant', 'en'];
const SLUG = /^[a-z0-9]+(?:-[a-z0-9]+)*$/;
const MAX_BODY_BYTES = 8 * 1024;

const str = (v) => (typeof v === 'string' ? v.trim() : '');
const len = (s) => [...s].length;

export function validateFeedback(input) {
  if (!input || typeof input !== 'object' || Array.isArray(input)) return { ok: false, field: 'body' };
  const v = {
    dialect: str(input.dialect),
    entry: str(input.entry),
    lang: str(input.lang),
    type: str(input.type),
    message: str(input.message),
    background: str(input.background),
    contact: str(input.contact),
  };
  if (!SLUG.test(v.dialect) || v.dialect.length > 64) return { ok: false, field: 'dialect' };
  if (!SLUG.test(v.entry) || v.entry.length > 100) return { ok: false, field: 'entry' };
  if (!LANGS.includes(v.lang)) return { ok: false, field: 'lang' };
  if (!FEEDBACK_TYPES.includes(v.type)) return { ok: false, field: 'type' };
  if (len(v.message) < 1 || len(v.message) > 1000) return { ok: false, field: 'message' };
  if (len(v.background) > 50) return { ok: false, field: 'background' };
  if (len(v.contact) > 100) return { ok: false, field: 'contact' };
  return { ok: true, value: { ...v, background: v.background || null, contact: v.contact || null } };
}

const json = (status, data) =>
  new Response(JSON.stringify(data), { status, headers: { 'Content-Type': 'application/json; charset=utf-8' } });

export async function handleFeedback(request, env, deps = {}) {
  const log = deps.log ?? console;

  let raw;
  try {
    raw = await request.text();
  } catch {
    return json(400, { error: 'body' });
  }
  if (new TextEncoder().encode(raw).length > MAX_BODY_BYTES) return json(400, { error: 'body' });

  let input;
  try {
    input = JSON.parse(raw);
  } catch {
    return json(400, { error: 'body' });
  }

  if (input && typeof input === 'object' && typeof input.website === 'string' && input.website.trim() !== '') {
    return json(200, { ok: true });
  }

  const result = validateFeedback(input);
  if (!result.ok) return json(400, { error: result.field });
  const f = result.value;

  try {
    await env.DB.prepare(
      'INSERT INTO feedback (dialect, entry, lang, type, message, background, contact) VALUES (?, ?, ?, ?, ?, ?, ?)',
    )
      .bind(f.dialect, f.entry, f.lang, f.type, f.message, f.background, f.contact)
      .run();
  } catch (err) {
    log.error('feedback: D1 insert failed', err);
    return json(500, { error: 'storage' });
  }

  if (deps.sendEmail && env.FEEDBACK_EMAIL_TO && env.FEEDBACK_EMAIL_FROM && env.SEND_EMAIL) {
    try {
      await deps.sendEmail(env, f);
    } catch (err) {
      log.error('feedback: email failed', err);
    }
  }

  return json(200, { ok: true });
}

function b64(s) {
  let bin = '';
  for (const byte of new TextEncoder().encode(s)) bin += String.fromCharCode(byte);
  return btoa(bin);
}

export function buildEmailRaw({ from, to, f, now = new Date(), id = crypto.randomUUID() }) {
  const subject = `[Familect] ${f.dialect}/${f.entry} · ${f.type}`;
  const body = [
    `方言：${f.dialect}`,
    `词条：${f.entry}`,
    `语言：${f.lang}`,
    `类型：${f.type}`,
    '',
    f.message,
    '',
    `方言背景：${f.background ?? '—'}`,
    `联系方式：${f.contact ?? '—'}`,
  ].join('\n');
  const domain = from.split('@')[1] ?? 'localhost';
  return [
    `From: Familect <${from}>`,
    `To: <${to}>`,
    `Subject: =?UTF-8?B?${b64(subject)}?=`,
    `Message-ID: <${id}@${domain}>`,
    `Date: ${now.toUTCString()}`,
    'MIME-Version: 1.0',
    'Content-Type: text/plain; charset=UTF-8',
    'Content-Transfer-Encoding: base64',
    '',
    (b64(body).match(/.{1,76}/g) ?? []).join('\r\n'),
  ].join('\r\n');
}
```

```astro
import { homePath, type Lang } from '../i18n/langs';
import { t } from '../i18n/ui';

interface Props {
  lang: Lang;
  placeholder: string;
  dialectId?: string;
  variant?: 'hero' | 'compact';
}
const { lang, placeholder, dialectId, variant = 'hero' } = Astro.props;
---
<form class:list={['search', `search-${variant}`]} role="search" action={homePath(lang)} data-search data-lang={lang} data-dialect={dialectId} data-empty={t(lang, 'searchNoResults')}>
  <input type="search" name="q" placeholder={placeholder} aria-label={placeholder} autocomplete="off" />
  {variant === 'hero' && <button type="submit" class="btn-primary">{t(lang, 'searchButton')}</button>}
  <ul class="search-results" role="listbox" hidden></ul>
</form>
<script>
  import { searchIndex, type SearchRecord } from '../lib/search';

  const cache = new Map<string, Promise<SearchRecord[]>>();
  function load(lang: string): Promise<SearchRecord[]> {
    let p = cache.get(lang);
    if (!p) {
      p = fetch(`/search/${lang}.json`).then((r) => (r.ok ? r.json() : Promise.reject(new Error(String(r.status)))));
      p.catch(() => cache.delete(lang));
      cache.set(lang, p);
    }
    return p;
  }

  for (const form of document.querySelectorAll<HTMLFormElement>('[data-search]')) {
    const input = form.querySelector('input')!;
    const list = form.querySelector<HTMLUListElement>('.search-results')!;
    const lang = form.dataset.lang ?? 'zh-hans';
    const dialect = form.dataset.dialect || undefined;
    let results: SearchRecord[] = [];
    let active = -1;

    const span = (cls: string, text: string) => {
      const s = document.createElement('span');
      s.className = cls;
      s.textContent = text;
      return s;
    };

    const render = () => {
      list.replaceChildren();
      if (!input.value.trim()) {
        list.hidden = true;
        return;
      }
      if (results.length === 0) {
        const li = document.createElement('li');
        li.className = 'search-empty';
        li.textContent = form.dataset.empty ?? '';
        list.append(li);
      }
      results.forEach((r, i) => {
        const li = document.createElement('li');
        li.setAttribute('role', 'option');
        if (i === active) {
          li.classList.add('is-active');
          li.setAttribute('aria-selected', 'true');
        }
        const a = document.createElement('a');
        a.href = r.url;
        a.append(span('sr-text serif', r.text), span('sr-pron', r.pron), span('sr-gloss', lang === 'en' ? `${r.en} · ${r.zh}` : `${r.zh} · ${r.en}`));
        if (!dialect) a.append(span('sr-dialect', r.dialectName));
        li.append(a);
        list.append(li);
      });
      list.hidden = false;
    };

    const update = async () => {
      const q = input.value;
      try {
        const index = await load(lang);
        if (q !== input.value) return;
        results = searchIndex(index, q, { dialect });
      } catch {
        results = [];
      }
      active = -1;
      render();
    };

    input.addEventListener('focus', () => void load(lang).catch(() => {}));
    input.addEventListener('input', () => void update());
    input.addEventListener('keydown', (e) => {
      if (e.key === 'ArrowDown' && results.length) {
        active = Math.min(active + 1, results.length - 1);
        render();
        e.preventDefault();
      } else if (e.key === 'ArrowUp' && results.length) {
        active = Math.max(active - 1, 0);
        render();
        e.preventDefault();
      } else if (e.key === 'Escape') {
        list.hidden = true;
      }
    });
    form.addEventListener('submit', async (e) => {
      e.preventDefault();
      if (active < 0) await update();
      const target = results[Math.max(active, 0)];
      if (target) location.href = target.url;
    });
    document.addEventListener('click', (e) => {
      if (!form.contains(e.target as Node)) list.hidden = true;
    });
  }
</script>
```

```js
// 构建产物冒烟检查（基于示例数据）。用法：npm run build && npm run verify
import { existsSync, readFileSync } from 'node:fs';
import { join } from 'node:path';

const dist = join(process.cwd(), 'dist');
const read = (p) => readFileSync(join(dist, p), 'utf8');
const failures = [];
const check = (ok, msg) => { if (!ok) failures.push(msg); };

const mustExist = [
  'index.html', 'zh-hant/index.html', 'en/index.html',
  'minnan/index.html', 'cantonese/index.html', 'en/cantonese/index.html',
  'minnan/a-ma/index.html', 'zh-hant/minnan/a-ma/index.html', 'en/minnan/a-ma/index.html',
  'cantonese/sik-zo-faan-mei/index.html',
  'search/zh-hans.json', 'search/zh-hant.json', 'search/en.json',
  'sitemap-index.xml', 'robots.txt', '404.html', '_headers', 'og.png', 'favicon.svg',
];
for (const p of mustExist) check(existsSync(join(dist, p)), `missing dist/${p}`);

for (const id of ['hakka', 'teochew', 'shanghainese']) {
  check(!existsSync(join(dist, id)), `soon dialect "${id}" should not have pages`);
}

if (failures.length === 0) {
  const hantList = read('zh-hant/minnan/index.html');
  check(hantList.includes('親屬稱謂'), 'zh-hant dialect page should show converted category names');
  check(hantList.includes('lang="zh-Hant"'), 'zh-hant page should have lang="zh-Hant"');

  const hantEntry = read('zh-hant/minnan/a-ma/index.html');
  check(/<h1[^>]*>阿嬷<\/h1>/.test(hantEntry), 'zh-hant entry headword must stay unconverted (阿嬷)');

  const minimal = read('minnan/to-sia/index.html');
  for (const word of ['例句', '各地说法', '使用提示', '字面意思']) {
    check(!minimal.includes(word), `minimal entry to-sia should not render "${word}"`);
  }

  const full = read('minnan/a-ma/index.html');
  check(full.includes('DefinedTerm'), 'entry page should have DefinedTerm JSON-LD');
  check(full.includes('rel="canonical"'), 'entry page should have canonical');
  check(full.includes('hreflang="zh-Hant"'), 'entry page should have hreflang alternates');
  check(full.includes('[待母语者确认]'), 'empty variant should show placeholder');

  check(read('en/minnan/a-ma/index.html').includes('Grandma (father'), 'en entry should show English meaning');

  const index = JSON.parse(read('search/en.json'));
  check(index.length === 12, `search index should have 12 entries, got ${index.length}`);
  check(index.every((r) => ['minnan', 'cantonese'].includes(r.dialect)), 'search index should only contain live dialects');

  const sitemap = read('sitemap-0.xml');
  check(sitemap.includes('/en/minnan/a-ma/'), 'sitemap should list English entry pages');
  check(!sitemap.includes('/404'), 'sitemap should not list 404');
  check(!sitemap.includes('/hakka/'), 'sitemap should not list soon dialects');
}

if (failures.length) {
  console.error(`verify failed:\n- ${failures.join('\n- ')}`);
  process.exit(1);
}
console.log('verify: dist looks good');
```
